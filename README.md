# Pixel Island

بازی پیکسلی مرورگری با دو نسخه:

- **Adventure:** فایل `adventure.html` — ماجراجویی، شهر، مزرعه، معدن و معبد.
- **Classic:** فایل `classic.html` — نسخهٔ اولیهٔ جمع‌آوری منابع و ارتقا.

صفحهٔ `index.html` ورودی انتخاب نسخه است. هر دو نسخه را می‌توان با لمس، ماوس یا کلیدهای جهت و WASD کنترل کرد.

## اجرای محلی

از ریشهٔ پروژه یک وب‌سرور ساده اجرا کنید، برای مثال:

```sh
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. برای خود بازی نیازی به نصب بسته نیست.

## تست‌ها

با Node.js 20 یا جدیدتر:

```sh
node --check adventure.js
node --check game.js
node --test tests/*.test.cjs
```

تست‌ها ثبات جهان و شناسهٔ منابع، یکسان‌بودن ذخیرهٔ دستی و خودکار، بازگشت وضعیت از سیو و مسیرهای ورود را بررسی می‌کنند. این تست‌ها جای تست گرافیکی در مرورگر را نمی‌گیرند.

## ذخیره و سازگاری

ذخیره‌ها در مرورگر و برای هر نسخه با کلید جدا نگه‌داری می‌شوند. تغییر مسیر نسخهٔ کلاسیک از `index.html` به `classic.html`، در همان دامنه و مرورگر به سیو قبلی آن دسترسی دارد. تغییر دامنه، پروتکل یا پورت می‌تواند فضای ذخیرهٔ جدا ایجاد کند.

قبل از به‌روزرسانی Adventure از بخش «پشتیبان» خروجی بگیرید. اصلاح تولید جهان چیدمان اولیهٔ قبلی و شناسه‌های آن را حفظ می‌کند، اما چیدمان‌هایی که قبلاً به علت باگ با موقعیت بازیکن تغییر کرده‌اند قابل بازسازی دقیق نیستند؛ چون خود آن چیدمان در سیو قدیمی ثبت نشده است. داده‌های موجودی، پیشرفت و شناسه‌های برداشت‌شده پاک یا بازنشانی نمی‌شوند.
